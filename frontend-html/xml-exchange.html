Syllabus Unit 5 Concepts Demonstrated

                    
    
                        
  • Well-Formed XML: Adheres to strict syntax rules (single root element, matching close tags, encoded entities).
    • 
                        
  • XML Schema Definition (XSD): Provides strongly typed data types (`xs:string`, `xs:integer`, `xs:decimal`, and `minInclusive`/`maxInclusive` restrictions for CGPA 0.0 to 10.0).
    • 
                        
  • Document Type Definition (DTD): Declares valid markup syntax, element containment rules, and enumeration attributes (`Upcoming | Completed | Cancelled`).
    • 
                        
  • DOM vs. SAX Parsing: Demonstrates tree-based document manipulation (PHP DOMDocument & Java DocumentBuilder) alongside streaming parser structures.
